# 소켓 알바

행사 단기 아르바이트 **모집 → 간편가입·지원 → 전자 근로계약 → 출퇴근 버튼 → 정산·임금명세서 → 월별 신고자료**까지 한 번에 처리하는 웹앱입니다.
단톡방에 공고 링크를 올리면, 근무자는 휴대폰으로 가입하고 현장에서 `근무 시작` / `근무 종료` 버튼만 누르면 됩니다.

GitHub → Vercel(자동 배포) → Supabase(Postgres) 구성입니다.

## 기능

**근무자 (휴대폰 화면)**
- 간편 가입: 이름 · 주민등록번호 · 휴대폰 번호 + 숫자 6자리 비밀번호 (계좌는 선택)
- 공고 보기 · 지원 (여러 날 행사는 가능한 날짜 선택) · 지원 취소
- 확정되면 근로계약서 등 서류를 읽고 손가락으로 **전자서명** → 서명해야 출근 버튼이 열림
- `근무 시작` / `근무 종료` 버튼 (서버 시각 기록, 행사장 위치 확인 선택)
- 근무 내역 · 실수령 예상액 · **임금명세서** · **근무확인서** 출력(PDF 저장)
- 내 정보(계좌·주소) 수정, 비밀번호 변경, 탈퇴

**관리자**
- 공고 등록: 일정·장소·인원, 시급/일급, 휴게(법정 자동/직접/없음), 절사 단위, 연장·야간 가산(5인 이상), 1일 수당, 공제 방식(일용근로소득세 / 3.3% / 없음), 고용보험, 필요 서류, 자동 확정, 현장 위치(GPS 반경)
- 최저임금(2026년 10,320원) 미달 공고 저장 차단, 예상 일급 미리보기
- **단톡방 모집 문구 자동 생성 · 복사**, 공고 복사해서 새 공고
- 지원자 확정/미선발, 대기 전원 확정, 가입자 직접 추가, 연소자(만 18세 미만) 표시
- 날짜별 출퇴근 현황(근무 중/종료/미출근), 지각·조기출근·위치 벗어남 표시, 시각 보정(원본 보존), 수기 등록, 미종료 일괄 종료, 일괄 확정
- 정산표: 기본급·연장·야간·수당·소득세·지방세·고용보험·실지급액, 지급완료 처리, CSV(엑셀)
- 서류 서식 편집기(`{{근로자명}}` 같은 자리채움 + 미리보기), 서명 현황, 재서명 요청·무효 처리
- 월별 신고자료 CSV: **일용근로소득 지급명세**, **근로내용확인신고(고용·산재)**, 사업소득 간이지급명세, 근로자 명부
- 월 8일 이상 근무자 경고(국민연금·건강보험 가입 검토), 개인정보 처리 기록(주민번호 열람·자료 내려받기 등)
- 근무자 검색, 주민번호 전체 보기(기록 남음), 비밀번호 초기화, 관리자 권한 부여

**기본 서식 3종** (관리자 > 서류 서식에서 수정 가능): 단기(일용) 근로계약서, 안전수칙 준수 및 비밀유지 서약서, 초상권(사진·영상) 활용 동의서

## 처음 설치 (약 15분)

### 1) Supabase
1. [Supabase 대시보드](https://supabase.com/dashboard) → New project → 이름 `socket-alba`, 지역 **Northeast Asia (Seoul)**
2. SQL Editor에 [`supabase/migrations/`](supabase/migrations/) 안의 SQL 파일을 번호 순서대로(`0001_…`, `0002_…`) 붙여넣고 Run
3. Project Settings → API에서 **Project URL**과 **secret(service_role) 키**를 복사

### 2) 비밀 값 만들기
```bash
npm run gen-keys
```
나오는 `SESSION_SECRET`, `ENCRYPTION_KEY`, `ADMIN_SETUP_CODE`를 안전한 곳에 보관하세요.
**`ENCRYPTION_KEY`를 잃어버리면 저장된 주민등록번호·계좌번호를 다시 읽을 수 없습니다.**

### 3) GitHub → Vercel
1. GitHub에 비공개 저장소를 만들고 이 폴더를 push
2. [Vercel](https://vercel.com/new)에서 저장소 Import (Framework: Next.js)
3. Environment Variables에 다섯 개 입력: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `SESSION_SECRET`, `ENCRYPTION_KEY`, `ADMIN_SETUP_CODE`
4. Deploy. 이후 GitHub에 push할 때마다 자동 배포됩니다.

### 4) 첫 관리자
배포 주소의 `/setup`에서 설치 코드(`ADMIN_SETUP_CODE`)와 관리자 이름·휴대폰·비밀번호를 입력합니다.
관리자가 한 명이라도 생기면 `/setup`은 더 이상 동작하지 않습니다. 다른 직원은 일반 가입 후 관리자 > 근무자에서 권한을 줍니다.

### 5) 회사 설정 → 공고 → 단톡방
관리자 > 회사 설정에서 사업자등록번호·주소·직인(투명 PNG)·문의 연락처를 넣고, 공고를 등록한 뒤 `문구 복사`를 눌러 단톡방에 붙여넣으세요.

## 로컬 실행
```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev
```

## 보안 설계
- 브라우저는 Supabase에 직접 접근하지 않습니다. 모든 조회·저장은 서버(Next.js)에서 secret 키로 하고, 모든 테이블에 RLS를 켜고 공개 키 권한을 없앴습니다.
- 주민등록번호·계좌번호는 AES-256-GCM으로 암호화해 저장하고, 화면에는 `900101-1******`처럼 가려 보여 줍니다. 중복 가입 확인은 키를 섞은 해시로 합니다.
- 비밀번호는 scrypt 해시, 5회 틀리면 10분 잠금. 비밀번호 변경·초기화 시 다른 기기 로그인은 자동 해제됩니다.
- 로그인 쿠키는 서명된 httpOnly 쿠키(30일). 주민번호 열람·신고자료 내려받기·출퇴근 보정 등은 처리 기록(`audit_logs`)에 남습니다.
- 탈퇴 시 근무 기록이 없으면 즉시 삭제, 있으면 근로기준법상 보존 의무(3년) 때문에 계정만 정지하고 기록은 보관합니다.

## 계산 규칙 (참고용)
| 항목 | 규칙 |
|---|---|
| 최저임금 | 2026년 시급 10,320원 |
| 휴게(법정 자동) | 휴게를 뺀 근로시간 4시간 이상 30분, 8시간 이상 1시간 |
| 연장·야간 가산 | 5인 이상 사업장 선택 시, 1일 8시간 초과분·22~06시분 시급의 50% |
| 일용근로소득세 | (일급 − 15만원) × 6% × 45%, 지방소득세 10%, 지급 1회 1천원 미만 소액부징수 |
| 사업소득 | 3% + 지방소득세 0.3% |
| 고용보험 | 근로자 부담 0.9% |

세율·보험요율·신고 기한은 바뀔 수 있으니 실제 신고 전에 세무사·노무사 확인을 권장합니다.

## 폴더 구조
```
src/app/(site)/     근무자 화면 (공고, 가입·로그인, 내 근무, 서류, 출력물)
src/app/admin/      관리자 화면, CSV 내려받기(export/[kind])
src/app/actions/    서버 액션 (auth, worker, admin)
src/lib/pay.ts      급여·세금 계산
src/lib/docs.ts     서식 자리채움, 모집 문구
src/lib/default-templates.ts  기본 서식
supabase/migrations/          DB 스키마
```
